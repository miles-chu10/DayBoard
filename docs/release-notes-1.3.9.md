# DayBoard 1.3.9 — Reopens instantly, and a Mac-style model picker

DayBoard 1.3.9 stops the dashboard from loading again every time you bring it back, and gives the
Assistant's model and effort picker a native look.

## New

- The Assistant's model and effort picker has a new Mac-style look: pick the model from a pop-up
  button, set effort on a slider with a **Reset** button, and turn Fast mode on with a switch. Effort
  levels and your saved choices are unchanged (#155).

## Fixed

- Closing the main window and reopening DayBoard from the Dock now shows the dashboard exactly as
  you left it, on the same view, instead of loading everything again. Moving between views also
  keeps what was already loaded on screen while it refreshes in the background (#153).
- Menus and popovers close more smoothly (#155).

## Updating

- **From 1.3.2,** DayBoard shows the Software Update window with these notes before it installs.
- Your data, sign-ins, trial and license stay where they are.

Apple Silicon, macOS 14+. AI and MCP remain optional.
